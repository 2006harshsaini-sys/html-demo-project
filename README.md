# 📚 HTML Demo Project

A simple multi-page website created using **HTML**. This project represents basic student information, educational background, experience, and projects. It was built to practice HTML fundamentals and understand how multiple web pages are connected.

---

## 🚀 Features

- 🏠 Home Page
- 🎓 Student Education Information
- 💼 Student Experience Information
- 📂 Student Project Information
- 🔗 External Links to GitHub and LinkedIn
- 📄 Multiple HTML Pages Connected with Navigation

---

## 📁 Project Structure

```
html-demo-project/
│
├── index.html          # Home page
├── education.html      # Education details
├── experience.html     # Experience details
└── project.html        # Project information
```
